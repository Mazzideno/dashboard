# Goodwill Language Solution - Staff Dashboard

Live staff dashboard for the Goodwill chatbot system.

## 🔗 Live Demo
**Dashboard:** https://mazzideno.github.io/dashboard/

## 🚀 Features
- Real-time conversation management
- Multi-staff support
- Media file handling
- Dark/Light theme
- Mobile responsive

## 📦 Backend
This dashboard connects to the production backend API hosted.
Backend code is private and secured.

## 🛠️ Technologies
- HTML5/CSS3/JavaScript
- Socket.io for real-time updates
- PostgreSQL database
- WhatsApp Cloud API integration
